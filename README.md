# YAMAE.FILM — Threads Film Archive

YAMAE.FILM의 공개 Threads 영상 게시물만 모아 최신 영상부터 감상하는 다크모드 아카이브입니다. 번호는 과거 날짜 기준으로 연속 부여됩니다.

## 주요 기능

- 2026-05-10부터 2026-09-15까지 확인된 공개 영상 263개
- 가장 오래된 영상을 001번으로 다시 매긴 연대기 정렬
- 카드 썸네일 263장 사용 (원본 미디어 번호를 안전하게 매핑)
- 데스크톱 5열 / 태블릿 4·3열 / 모바일 2열 반응형 갤러리
- 데스크톱 20개, 모바일 12개 단위 무한 스크롤
- 썸네일 클릭 시 중복 포스터 없이 영상 플레이어를 실제 영상 폭에 맞춰 표시
- 게시물 내용·날짜·원문 링크는 영상 아래에 배치
- 공식 Threads 임베드 기반 원본 영상 재생
- 첫 화면 최신순 로딩, 과거순/최신순 전환, 번호·날짜·게시물 코드·내용 검색

## 로컬 실행

정적 파일만 사용하므로 간단한 웹 서버에서 바로 실행할 수 있습니다.

```powershell
python -m http.server 4173
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. Node가 있다면 저장소의 `dev-server.cjs`를 사용해도 됩니다.

## 데이터와 썸네일

`posts.js`에는 324개 공개 미디어 게시물의 코드와 작성 시각이 저장되어 있습니다. 앱은 이 중 영상으로 확인되고 현재 공개 상태인 게시물 263개만 화면에 표시하고 001~263번으로 순차 번호를 부여합니다. Threads가 “Thread not available”을 반환한 9개는 깨진 미리보기를 만들지 않도록 제외했습니다. `thumbs/001.jpg` 같은 로컬 썸네일은 원본 미디어 번호와 매핑되어 표시됩니다.

`scrape-thumbnails.cjs`는 각 게시물의 공개 `og:image`를 `thumbs/`에 저장하고 `post-meta.json`에 내용 메타데이터를 기록합니다. 실제 영상은 만료되는 CDN 파일을 복제하지 않고 Threads 원본 임베드 경로로 불러옵니다.

## GitHub Pages

저장소 루트의 정적 파일을 `main` 브랜치에서 GitHub Pages로 제공하면 별도 빌드 없이 공개할 수 있습니다. `.nojekyll` 파일이 포함되어 있어 `thumbs/`의 정적 경로가 그대로 유지됩니다.
